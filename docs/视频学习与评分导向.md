## 3. 已核验的官方要求

以 [2026 论文格式规范](https://www.mcm.edu.cn/html_cn/node/4cd596519c9eb9fbd866398f6df0caa3.html) 为准：正文不含目录且最多 30 页；附录提供完整可运行程序和支撑材料清单；电子论文从摘要页开始，不含承诺书与编号页。匿名范围覆盖摘要、正文、附录及支撑材料。视频“只放核心代码”不能采用。

依据 [官方 AI 工具规定英文版](https://en.mcm.edu.cn/html_en/node/532f38e63cfa84145697e2678575ba0a.html)（2026-08-03 发布，9 月 1 日试行）：核心建模分析由队伍主导，逐项人工核验 AI 内容；参考文献前放使用声明，支撑材料附使用详情 PDF，记录工具、环节、提示方式及采纳/修改/核验情况。中文文件名与措辞可对照 [中文转载](https://www.cmathc.org.cn/mcm/tz/602.html)，提交前再核对中文官方文件和本队赛区通知。

## 4. 针对 Codex 的薄弱点设置检查

| 常见薄弱点 | 必须留下的证据 |
|---|---|
| 跳过读题，套熟悉的模型 | 每问目标、输入、输出、单位、约束与原文定位表；关键歧义由团队确认。 |
| 堆高级算法 | 简单基线、采用复杂方法的必要性、与基线的同条件对照。 |
| 默认假设合理 | 假设来源、适用范围、反例、敏感性与不成立时的影响。 |
| 代码能跑就宣称模型正确 | 量纲、边界算例、约束残差、守恒关系、公式到代码映射。 |
| 漂亮结果掩盖不可行 | 原始 solver 状态、随机种子、可行性、误差与不确定性，禁止将未证最优写成最优。 |
| 编造文献和统计事实 | 可访问原始来源及准确定位；无法核验的内容明确标记，不能写成结论。 |
| 版本改动后前后不一致 | 上游结论版本/hash、下游过期标记与重新计算/审查记录。 |
| 摘要空泛、论文与代码脱节 | 每问任务—模型—方法—数值结果四要素，结果表能从交付代码重现。 |

实施顺序：读题并共同确认 → 简单基线 → Harness 逐问研究/计算/门禁 → 团队复核 → 必要的稳健性与对照实验 → 基于已验证结果整理论文。所有 PASS_WITH_WARNING 均带原因和适用限制。
