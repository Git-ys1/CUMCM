# 评审意见的数据核验

## 1. 弃光变量是否必须

- 光伏富余 SURPLUS = PV − L 的最大值：**6602.0 kW**（储能最大充电功率 5000 kW）
- SURPLUS > 5000 kW 的时段数：**241** / 52560（占比 0.459%）
- 若不设弃光变量且不允许上网售电，这些时段**数学上必然不可行** → **必须引入弃光变量 $W_t$**。
- 这些时段的被迫弃光电量合计：16297.1 kWh；单时段最大被迫弃光：267.00 kWh
- 注：以上仅由**功率上限**推出，是弃光电量的**下界**；若储能在富余时段已达容量上限，实际弃光更多。

## 2. 问题1（平均典型日）是否被迫弃光

- 平均日 SURPLUS 最大值：2117.5 kW（< 5000 kW，**功率层面不构成被迫弃光**）
- 平均日午间富余电量合计：6248 kWh
- 若 0:00 与 24:00 均为 6000 kWh，则从 6000 起充、可用净空间约 9600 kWh（受安全上限约束），从 6000 起算可吸收 4800 kWh
- 富余电量 6248 kWh ≤ 最大可吸收 9600 kWh→ **功率与容量均不构成被迫弃光**，但 LP 仍可能因经济性选择少量弃光

- **高估光伏（e > 0，危险方向）** 占比：**25.7%**；低估（e < 0）占比 74.3%
- e > 0 时的条件均值 807.9 kW；e < 0 时的条件均值 -569.8 kW

- **结论**：e > 0（预测高于实际 → 计划买少了 → 缺口 → 5 倍紧急购电）占约一半，是必须防范的方向；评审指出的「高估光伏才是危险方向」成立。

## 4. Q2 自建日前光伏预测的可行性（历史可用长度）

- 附件2 覆盖 2025-01-01 ~ 2025-12-31，共 365 天
- Q2 结果从 2025-02-01 起报 → **1 月共 31 天可作为预测模型的训练/预热窗口**
- 候选方法：① 前 k 天同刻点滑动平均（k=7/14/30）；② 晴空模型（日照几何）+ 逐日衰减系数；③ 前一日同时刻持续法
- 注意：仅单一年份数据，无法使用「去年同日」类季节性样本
