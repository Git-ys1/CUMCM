## 4. 模型实现规范（按锁定模型）

### 4.1 变量（单日 $T=144$）

| 变量 | 含义 | 上界 |
|---|---|---|
| $G_t$ | 购电量（kWh） | — |
| $C_t$ | 充电量，**母线侧**（kWh） | 833.33 |
| $H_t$ | 放电量，**母线侧**（kWh） | 833.33 |
| $S_t$ | 储电量（kWh） | [1200, 10800] |
| $W_t$ | 弃光电量（kWh） | $[0,\ P_t\Delta t]$ |
| $E_t$ | 紧急购电量（kWh） | ≥ 0 |

### 4.2 约束（逐条落地）

$$
G_t + P_t\Delta t + H_t + E_t = L_t\Delta t + C_t + W_t \tag{平衡}
$$

$$
S_t - S_{t-1} - 0.9\,C_t + \tfrac{1}{0.9}H_t = 0 \tag{SOC 递推，等式}
$$

> **注意**：平衡式中**不出现**效率系数——效率已全部进入 SOC 递推。这是母线侧定义的关键，写错会导致能量不守恒。

$$
1200\le S_t\le 10800,\quad 0\le C_t,H_t\le 833.33,\quad 0\le W_t\le P_t\Delta t,\quad E_t\ge 0
$$

- Q1 追加：$S_0 = S_{144} = 6000$
- Q2–Q4 追加：$S^{(d)}_0 = S^{(d-1)}_{144}$，$S^{(1)}_0 = 6000$

**同时充放、同时弃光与紧急购电**均无需 0-1 变量：二者都是纯损耗，最优解自动排除（代码中可用 `assert not (C>eps and H>eps)` 做断言校验）。

### 4.3 目标函数与分段线性费用（关键，勿写错）

替代口径下（已锁定）：

$$
\text{Cost}_t = p_t\Big[\min(G^p_t,G^a_t)+0.5(G^p_t-G^a_t)^+ + 1.5(G^a_t-G^p_t)^+\Big] + 5p_t E_t
$$

**线性化（只用一个辅助变量，已推导验证）**：引入 $b_t\ge 0$，约束 $b_t \ge G^a_t - G^p_t$，则

$$
\boxed{\ \text{Cost}_t = p_t\big(0.5\,G^p_t + 0.5\,G^a_t + b_t\big) + 5p_tE_t\ }
$$

最小化时 $b_t=(G^a_t-G^p_t)^+$，还原后与分段式完全一致。

**数值自检（必须做）**：求解后逐时段核对
`0.5*Gp + 0.5*Ga + b` 与 `min(Gp,Ga) + 0.5*max(Gp-Ga,0) + 1.5*max(Ga-Gp,0)` 的差应 $<10^{-6}$。

| 校验样例 | $G^p$ | $G^a$ | 期望费用（$p=1$） |
|---|---|---|---|
| 下调 | 900 | 700 | **800** |
| 不调 | 900 | 900 | 900 |
| 上调 | 700 | 900 | **1000** |

> 若误用叠加口径作对照，公式为 $\text{Cost}_t = p_t(G^p_t + 0.5(G^p_t-G^a_t)^+ + 1.5\,b_t) + 5p_tE_t$，需另存分支，不得与主口径混用。

## 5. 四问求解流程与信息集

| 问 | 流程 | 随机性 | 信息集硬约束 |
|---|---|---|---|
| Q1 | 单日 LP，$S_0=S_{144}=6000$ | 无 | 附件1 即为已知 |
| Q2 | ① 用 **$d$ 日之前**的实际光伏预测 $\hat P_d$ → ② LP 得全天 $G^p$ → ③ 实际 $P$ 结算得 $E$、$W$ → ④ 当日数据入库 | 预测参数估计需固定 seed | 预测不得用 $d$ 日及以后数据；日内不得改 $G^p$ |
| Q3 | 0:00 出全天基准 $G^{(0)}$ → 6/12/18 用新预报重优化**剩余时段** → 只执行至下一节点 → 结算比较 $G^{(0)}$ vs $G^a$ | 无 | 计划层不得用附件2 实际光伏；$G^a$ 取执行前最后一次值 |
| Q4 | 同 Q2/Q3，$p_t \to \lambda_{d,t}$ | 电价历史预测需固定 seed | 电价预测只用历史窗口 |

**Q2 储能实时缓冲**：$G^p$ 锁定；$C_t,H_t$ 按实际偏差调整。信息集
$\mathcal I_t=\{0{:}00\ \text{计划},\ 0{:}00\ \text{预测},\ \text{截至 }t\ \text{的实际值},\ S_t\}$，
**禁止**用 $t$ 后真实值与附件3 新预报。实现：主用贪心反馈，对照用周期再优化（$m=6$）。

**末端效应**：建议每天 0:00 优化未来 $K=3$ 天、只执行第 1 天；或加终端 SOC 惩罚。
