## 5. 最终判定

$$
\boxed{\text{有条件合适}}
$$

**判定依据**：线性规划在任务对齐、输出对齐、数据充分性、可解释性、计算可行性与验证可行性上**完全成立**；但字典记录 797 明列的关键假设"**数据参数确定**"在 Q2–Q4 被系统性破坏（光伏不确定、预报滚动刷新、电价实时波动），且其缺陷项直接点名"参数不确定时最优解脆弱"。因此 LP **不能裸用**，必须满足下列前置条件后才成立：

1. **补弃光变量 $W_t$** —— 否则 Q2–Q4 实测有 241 个时段不可行；
2. **凸分段线性费用显式线性化**（引入辅助变量表达 $\max\{\cdot\}$）—— 否则偏离 LP 假设；
3. **外套预测层与滚动层**（MPC 结构）—— 以消解"参数确定"假设的违背；
4. **信息集硬隔离** —— 计划层不得使用实际光伏、未来电价；
5. **对不确定参数给出随机/鲁棒对照** —— 用于量化"确定性 LP"的乐观程度（可用字典 971 的 **EVPI / VSS** 指标）。

若不做第 1 项，判定直接降为**不合适**（不可行）；若不区分问题 1 与问题 2–4 而一律裸用确定性 LP，则问题 2–4 的判定为**不合适**（违反核心假设）。

## 7. 落地与论文写作建议

**预处理**：统一 $\Delta t=1/6$ h 与 kW→kWh 换算；附件第 $t$ 个数据 ↔ 模板第 $t$ 个位置（不平移）；小时预报降尺度到 10 min。

**建模**：按锁定模型写母线平衡 + SOC 递推 + 分段线性费用；显式加入 $W_t$；声明效率口径（母线侧、充放各 90%）。

**求解设计**：

- Q1：单日 LP，$S_0=S_{144}=6000$；
- Q2：自建日前光伏预测（日内形状 × 日幅值）→ LP → 全天锁定 $G^p$ → 实时储能缓冲 → $E$ 结算；
- Q3：0 点全天基准 + 6/12/18 滚动重优化 + 单次差额结算；
- Q4：$p_t\to\lambda_{d,t}$ 重算 Q2/Q3，另加"历史电价预测"对照。

**参数/约束选择**：安全裕度 $q$ 网格 $\{0.80,0.85,0.90,0.95\}$；滚动时域 $K=3$ 天削弱末端效应；Q2 实时缓冲主用贪心、周期再优化 $m=6$ 作对照。

**验证指标（按字典 797 的检验方法落地）**：

| 类别 | 指标 |
|---|---|
| 最优性 | **对偶间隙 = 0**；与内点法结果对比 |
| 约束 | 逐时段**约束违反度**；SOC 越界次数；弃光与理论下界 16 297 kWh 对照 |
| 解释 | **影子价格/灵敏度分析**（解释充放电时机） |
| 稳健性 | **参数扰动（RHS/系数）测试**：效率口径、5000 kW 释义、负载 ±3%/±5% |
| 不确定性价值 | **EVPI / VSS**（字典 971）——量化"若预知光伏/电价能省多少" |
| 交叉验证 | Q1 与 DP 网格解对比（网格加密收敛） |
| 求解性能 | 大实例求解时间、迭代次数 |

**论文必须报告的局限**（对应字典 797 缺陷项）：线性假设对实际的简化；参数不确定时最优解的脆弱性（尤其是点预测驱动的 Q2）；以及我们如何用滚动/随机/鲁棒对照来缓解。
