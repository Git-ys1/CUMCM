## 三、锁定口径速查（一页纸）

```
母线平衡   G_t + (P_t·Δt − W_t) + H_t + E_t = L_t·Δt + C_t
SOC 递推   S_t = S_{t−1} + 0.9·C_t − H_t/0.9      （母线侧定义）
约束       1200 ≤ S_t ≤ 10800 ; 0 ≤ C_t,H_t ≤ 833.33 ; 0 ≤ W_t ≤ P_t·Δt ; E_t ≥ 0
Q1         S_0 = S_144 = 6000 kWh
Δt         1/6 h（10 min，144 槽/天）

Q2   只用附件1电价 + 附件2；自建日前光伏预测；负载视为 0:00 已知
     G^p 全天锁定；C/H 实时反馈缓冲；缺口 E 按 5p；日内不重优化
     数据库严格滚动（第 d 日只能用 d 日之前数据）；1 月 = 训练 + SOC 预热
Q3   0 点出全天 144 时段基准 G^(0)；6/12/18 重优化但只执行至下一节点
     G^a = 执行前最后一次有效调整值；单次差额结算（不逐次收费）
     费用 = p[min(Gp,Ga) + 0.5(Gp−Ga)⁺ + 1.5(Ga−Gp)⁺] + 5p·E
Q4   p_t → λ_{d,t}（附件4）重算 Q2/Q3；另设"历史电价预测"对照

时间   附件第 t 个数据 ↔ 模板第 t 个位置，不平移，不断言端点语义
结果   2025.2.1–12.31（334 天）；5 个 xlsx
```

**仍开放（不阻塞）**：Q2 具体光伏预测算法、实时缓冲取贪心还是周期再优化、Q3 重优化时域是否含次日。
