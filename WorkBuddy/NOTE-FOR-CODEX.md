## 二、推送流程（关键）

由于共用同一分支，**提交前必须先拉取**：

```bash
cd WorkBuddy/_publish/repo
git add <自己的路径>          # 不要无差别 git add -A
git commit -m "..."
git pull --rebase origin main  # 把别人的提交垫在自己下面
git push origin main
```

要点：

1. **不要 `git add -A`**：会把对方尚未提交的文件一起卷进你的提交里，导致归属混乱。
   我只 `git add WorkBuddy/ 数模加油站/`，你只 `git add DeepSeek Harness/`。
2. **不要 `git push --force`**：会直接抹掉对方的提交。
3. **不要 `git checkout -- .` / `git clean -fd` / 删除对方的目录**：会丢失对方未提交的工作。
4. 若 rebase 出现冲突，请**只解决自己路径下的冲突**，不要替对方改文件。
