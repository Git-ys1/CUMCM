# 发给网页端 GPT 的提示词（C 题获奖论文「统一方向标」提取）

> 使用方式：把本文件全文复制，粘贴到网页端 GPT（具备图像/PDF 视觉读取能力的版本）对话框；**先上传** `00_论文清单与索引.md` 中列出的 17 个整理后文件（PDF 直接传、ZIP 解压读图），再发送本提示词。建议按年份分批（每批跑同一提示词），最后人工合并 P1/P2/P3 频次。
> 性质：这是**实证归纳任务**（从获奖论文提取结构性共性），不是写作、不是帮你建模型。所有结论必须附证据链，禁止无证据的观点总结。

## 一、角色与任务

你是数学建模竞赛论文的资深评委助理。本次任务：从历年 C 题**确定性获奖论文（2020–2025 共 17 篇）**中，提取一份《C 题获奖论文统一方向标 V1》，作为正在构建的 **2026 国赛 C 题（微网与外部电网电力调控 / 微网购电滚动优化）V4 论文**的「评委视角验收清单」。

- 你会看到 17 个文件（4 个 2020 PDF、4 个 2021 ZIP、3 个 2022 ZIP、4 个 2024 PDF、2 个 2025 PDF），**全部为扫描件，无文字层**，请用视觉逐页读取。
- ZIP 内图片已按页序命名（`C01.jpg…` / `001.jpg…`），按文件名顺序即等于真实页序，请严格按序阅读，勿跳页、勿乱序。
- 你不修改任何外部文件，只产出一份方向标文本。

### 2.2 C 题评阅模式要点（提炼自官方评分细则精神，用于 P1/P2 判定）
- 特殊数据结构 + 可验证决策：结构零值/缺失、成分约束、重复测量、时间序列、层级、跨期依赖都必须显式处理并解释数据如何生成。
- 问题之间要有**真实传递输出**（前一问结果为后一问输入），不能各问孤立。
- **防泄漏 / 可观测性**：训练/预测只允许用语义可得信息，禁止未来信息穿越。
- 必须能从**最终的提交解独立复算**目标值与硬约束（评阅会复核）。

### 2.3 跨案例稳定模式精神（23 条提炼，用于 P2 支撑）
得分结构普遍包含：明确的问题重述与输出形式、显式假设及依据、可复现的求解（软件/算法/停止条件）、量化检验体系（灵敏度/误差/对比基线）、按题面模板填满结果表、图表与正文一致、单位口径统一。凡与这些精神一致且频次达标的条目，可定级 P2。

## 三、执行流程（三步，逐步进行，禁止跳步）

**第 1 步 · 逐篇结构化编码**：对 17 篇每篇生成一张「论文画像卡片」，固定 8 个维度（见 §四）。每格必须写证据位置（文件名 + 页码或图号，如 `2020C_01 p3`、`2021C_03 C12.jpg`）。图像模糊/不可读的格子写「无法核验」，不得脑补。

**第 2 步 · 跨篇频次统计**：按 8 维聚合，输出每项特征的覆盖篇数与占比，以及分布统计（中位数、区间），例如「假设条数：中位 6 条（区间 4–8）」。所有数字必须来自第 1 步实测，逐篇统计，不得估算后当实测。

**第 3 步 · 三角验证与定级**：论文实证 ↔ 官方评分细则/评阅要点 ↔ 跨案例稳定模式。定级规则：
- **P0 硬红线** = §2.1 已列 10 条（与频率无关）；
- **P1 高频共性** = 出现 ≥60%（17 篇中 ≥11 篇，按有效核验篇数折算）且与评阅口径一致；
- **P2 稳定模式** = 出现 30%–59% 且得到官方口径或稳定模式支持；
- **P3 差异亮点池** = 仅少数年份出现、但对 2026 C 题（微网购电滚动优化）机制同构的做法；
- 低于 30% 且无官方支持 → 不进方向标。

## 四、统一编码表（每篇必填 8 维）

| 维度 | 编码要点（全部要求可观测、可计数） |
|---|---|
| **A 结构与篇幅** | 章节清单与顺序；摘要字数/是否 1 页；正文页数（≤30 红线）；附录页数/占比；图表张数 |
| **B 摘要要素** | 问题/方法/量化结果/检验/结论五要素覆盖率；量化结果条数 |
| **C 问题分析** | 题型归类、跨问联动、技术路线图有无 |
| **D 假设** | 条数、来源是否写明「依据」、与后文模型的对账 |
| **E 模型建立与求解** | 模型类型、针对题目的改造点、参数来源、可复现要素（软件/算法/停止条件） |
| **F 检验体系** | 存在几种检验（物理守恒/防泄漏/灵敏度/误差/对比基线）；是否量化 |
| **G 结果与表达** | 结果表按题目模板的覆盖度；图/表/正文一致性；单位与口径 |
| **H 合规与匿名** | 匿名、AI 声明位置与内容、结果文件/支撑材料清单 |

## 五、证据纪律（违反即返工）

1. 每条 P1/P2 条目必须附证据链「论文×N（文件名，位置）」，少于 2 篇实证不得标 P1/P2。
2. 禁止编造论文内容；没读到的部分必须如实标注覆盖度（如「2021/2022 仅核验摘要与结构页」）。
3. 只提取**结构性模式与做法**（如「获奖论文普遍把结果表按原题模板逐格填满」），不得把获奖论文的原文段落、公式、图表或具体数据复制进方向标（版权与查重红线，同样约束 V4）。
4. 区分三类结论：**共性**（多篇同有）/ **趋势**（随年份演化）/ **差异**（单篇特色），分列不混写。
