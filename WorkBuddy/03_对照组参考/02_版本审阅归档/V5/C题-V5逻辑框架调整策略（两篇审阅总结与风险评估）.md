## 篇二 · GPT 最新讨论：Q3 结算口径拍板（用户已确认"今后就这样定"）

**核心变更**：调整购电量与计划购电量的区别——**主结算改为"差额部分结算"**。

- **公式**：`C_t = p_t·min(Gᵖ,Gᵃ) + 0.5·p_t·(Gᵖ−Gᵃ)⁺ + 1.5·p_t·(Gᵃ−Gᵖ)⁺`，不足再加 `5·p_t·E_t`。
- **判例**：计划 5000 → 调整 4000 = **4000p + 1000×0.5p = 4500p**（**不是** 5000p + 500p = 5500p）；计划 4000 → 调整 5000 = 4000p + 1000×1.5p = 5500p（与旧法相同）。
- **两套解释只在"向下调整"时分歧**（向上一致）——这正是此前长期未察觉分歧的原因。
- **改判理由**：题面两处强调"**部分**""超出部分""**违约电价**"，支持"共同部分正常、差额部分特殊价"；旧法导致"少买反而多花钱"，向下调整被经济抑制，制度意义弱；山东中长期交易规则可作旁证（实际用电按合同价结算 + 少用部分付偏差费）。
- **结果影响**：Q3 主结果 **13 917 403.19 → 13 727 989.23 元**（差 189 413.96 元）。
- **必须同步重生成**：`result3.xlsx`、Q3 四节点消融、Q3 指定四日表、Q3 典型日图、Q3 费用分解、**Q4-3 与 `result4-3.xlsx`**、摘要/正文/图表/测试。
- **不受影响**：**Q1、Q2、Q4-2 不变**。
- **保留不动**：V4 全部物理约束、因果信息、滚动执行、预报校正、**MILP 充放互斥**——只换结算公式重跑。
- **命名**：今后不再说 additive / replacement，直接称 **"差额部分结算"**。

> 与篇一的关系：**完全一致**。篇一 §8 已要求"Q3 主模型应重新回到差额结算"，篇二给出了最终拍板理由与判例。两篇在这一点上**互相印证、无冲突**。

# 第二部分　全文重新撰写的风险性评估

## 结论：**不建议全文重写，建议"结构重组 + 定向改写"**

| 风险 | 等级 | 机理 | 规避方式 |
|---|---|---|---|
| **数值脱钩** | 🔴 高 | V4 所有结果数字由 `numbers.tex` 宏注入（`report.py` 生成），正文手改数字 → 与代码/工作簿脱钩，`test_paper_consistency` 立即失效 | **禁止手改任何数字**；数字只由宏注入，口径切换后重跑自动更新 |
| **公式与文字矛盾** | 🔴 高 | 结算口径切换后，若只改文字不改公式（或反之），式 (25)、符号 `u/v`、费用分解句会自相矛盾 | B 级成对改：公式、符号、分解句、结论句**必须同步** |
| **验证链断裂** | 🔴 高 | V4 已建立 5 类自动验证（物理残差/mutation/结算单测/计划持续性/历史回归 + Excel 回读）；全文重写后测试与正文可能不再描述同一模型 | 重跑后**必须重跑全部测试**，并把测试结果同步进正文表述 |
| **交叉引用断裂** | 🟠 中 | 章节重组会打乱 `\label/\ref/\eqref`（21 个公式标签本就未被引用，8 幅图/24 表全部被引用） | 重组时**保留全部 `\label` 原样**，只移动位置；最后全量编译核对 |
| **30 页超限** | 🟠 中 | 正文现为 **恰好 30 页、零余量**；任何新增（含技术路线图、新实验）都会越限 | 每阶段编译核页；新增必先删减等量 |
| **题面漏项** | 🟠 中 | 重写时易丢失题面硬要求：四个指定日期表（表 1–3 格式）、不售电、首末 SOC、334 天窗口 | 保留 Vulcan 清单（见第四部分"必保项"） |
| **术语/版权** | 🟡 低–中 | 参考范文（含即将到来的全糖奶茶屋示例）**只可学格式与写法，不得抄文字/公式/图表** | 只采纳"公式典范/段落范式"，内容自研 |
| **AI 观感反升** | 🟡 中 | 大段重写若由 agent 产出，反而加重 AI 味（用户已明确判断：论文写作 agent 不如 chat 级 | **文字由人工写**，agent 退出撰稿 |

### 为什么"逻辑框架的调整"才是正解

AIGC 审计已证明：**V4 的表层语言指标全部干净**（连接词 1.60%、被动句 0.23%、引文全通过、数值全自洽，最终风险分 **13.6/100 = 🟢 低风险**）。
唯一 🟠 标红的是**维度 9 术语一致性**（"口径"50 次、结算规则多套命名并存）。
⇒ **问题不在"词"，在"框架"**：V4 是按"信息集分层 + 口径审计"的内部逻辑组织的，而题面/读者要的是"Q1→Q4 递进"的自然逻辑。
⇒ 因此：**改框架（章节主线 + 术语体系），保内核（物理/因果/MILP/数值链）**，是风险最小、收益最大的路径。
