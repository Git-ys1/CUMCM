## 7. 给 MathModel V3 的采纳 / 规避清单

**✅ 采纳（已多方印证）**
1. Q1 全天购电量锁定 **59482.7 kWh**、购电费 **35126.95 元**（固定 S0=S144=6000）。
2. 充放效率 η=0.9 单值（充×0.9 / 放÷0.9）、单段 ≤833.3 kWh、SOC[1200,10800]、功率 ≤5000 kW、母线侧功率变量、不加 0-1 充放互斥（往返 0.81<1，LP 自动避免）。
3. **必须有弃光变量**（蒋实测 241 时段不可行；张/顾/吕无弃光是缺陷）。
4. Q2 **必须跑诚实预报**（用决策时可获得的 0:00/近期预报，walk-forward，不泄漏当日实际）→ 我们的 mean7=14.27M 合理；**同时报完美信息下界 12.2–13.8M 作对照**，点明"紧急=0 是下界非答案"。
5. Q2 **统一日数并报双口径**（全年 365 + 报送 334）。
6. Q3 **0:00+6:00+12:00 三次滚动重优**；18:00 仅条件触发（许/蒋实证边际极低）。
7. 许的**分位数安全裕度 + CVaR + 灵敏度分析**框架用于可靠性与敏感性章节。

**⛔ 规避（他人踩过的坑）**
1. **Q2 勿用附件2实际值当计划**（完美信息陷阱，紧急=0，蒋/顾对照/两 agent 均中招）。

3. **勿漏弃光变量、勿漏灵敏度分析**（吕的硬伤）。
4. **表1「10:00–10:10」取第 60 行**（模板行序，与蒋一致；胡取第 61 行属已知分歧，论文需声明）。
