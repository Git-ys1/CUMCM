# C题独立建模报告

## 1. 数据与统一口径

- 时间粒度为10分钟，单日144槽，Δt=1/6 h。
- 功率输入单位为kW；购电、充放电、弃光和紧急购电变量均为每槽kWh。
- 附件第t个数据按位置对应官方模板第t个数据单元，不做左右移位。
- 附件2共365天；1月用于预测与SOC预热，五个年度结果文件均输出2月1日至12月31日334天。
- 储能采用母线侧充放电：充、放效率各0.9；SOC范围1200至10800 kWh；单槽充放电上限5000/6 kWh。

## 2. 共享线性规划

每槽满足：

G_t + P_t Δt + H_t + E_t = L_t Δt + C_t + W_t

SOC递推：

S_t = S_(t-1) + 0.9 C_t - H_t/0.9

其中G为计划或调整购电，C/H为母线侧充/放电，W为弃光，E为被动紧急购电。Q1计划层取E=0，Q2-Q4的E由实际执行层产生。

主目标求解后，程序依次最小化储能吞吐量和弃光，消除自由弃光造成的等价最优退化。HiGHS原始与对偶容差为1e-9；词典序容差为max(1e-5, 1e-10×目标尺度)。

## 3. 问题1

附件1的负载、光伏和电价均视为已知，求解单日确定性LP，并约束S_0=S_144=6000 kWh。目标为最小化Σp_t G_t。

## 4. 问题2

### 4.1 信息集

第d天0:00的光伏预测只能使用第d天以前的附件2实际光伏。全天计划购电G^p锁定；日内不得使用附件3或未来实际光伏修改G^p。

### 4.2 在线预测

候选基模型包括前一日持续、7/14/30日滚动均值、14/30日线性加权均值。每个模型叠加q80、q85、q90、q95四个历史正偏差安全边际。第d天候选选择只依据此前30天的非对称费用代理：

Σ p_t [4(预测-实际)^+ + (实际-预测)^+] Δt。

权重4对应“高估光伏后可能承担5倍紧急电价，相对正常购电多付4倍”的边际风险。

### 4.3 实时执行

计划购电保持不变。每槽发现缺口时先减计划充电、再增加放电，仍不足才紧急购电；发现富余时先减放电、再增加充电，仍富余才弃光。控制器只读取当前实际值和当前SOC。

每日计划终端SOC约束为当日真实初始SOC；真实终端SOC不重置，直接继承到次日。该终端策略与自由终端、多日滚动等备选方案均登记在决策台账。

## 5. 问题3

### 5.1 计划与滚动调整

0:00使用附件3预报制定全天基准G^p。6:00、12:00、18:00分别重优化未来24小时的购电和储能，但只执行到下一个6小时节点。跨午夜只继承SOC，次日0:00重新形成基准。

附件3的24个小时值用线性插值映射到10分钟端点。阶梯保持作为敏感性变体完整保留。

### 5.2 因果偏差校正

四个发布节点分别维护过去30天执行块预报误差，并在线选择q80至q95下修边际。第d天校正不使用第d天实际值。原始预报、不校正阶梯、校正阶梯、校正线性均可由参数化脚本重跑。

### 5.3 替代/差额结算

主口径为：

Cost_t = p_t [0.5G^p_t + 0.5G^a_t + b_t] + 5p_tE_t

其中b_t≥G^a_t-G^p_t、b_t≥0。最优时b_t=(G^a_t-G^p_t)^+。程序逐日用原分段式复算，最大差异低于1.46e-11元。叠加口径仍作为敏感性输出。

## 6. 问题4

Q4-2完整复用Q2流程，Q4-3完整复用Q3流程，仅将电价替换为附件4的365×144实时序列。在线模型评分也使用对应历史日的附件4电价。

## 7. 风险和后续变体

- Q2每日计划终端回到日初会限制跨日套利；三日滚动是优先增强变体。
- Q3的偏差校正按非对称费用代理选择，降低紧急购电但可能增加弃光，不能只用MAE评价。
- 附件4主方案按题意直接使用给定电价重算；若把未来电价视为未知，应另建历史电价预测变体。
- 充放效率“各90%”与“往返90%”、5000kW独立/共享上限仍需做论文敏感性。
