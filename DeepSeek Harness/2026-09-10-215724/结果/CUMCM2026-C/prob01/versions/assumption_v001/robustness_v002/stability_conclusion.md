## 4. 脆弱参数、方向与幅度

1. **load 是最脆弱参数（首要技术债）**：
   −20% → `22159.431` 元（−36.916%）；+20% → `50929.885` 元（+44.988%）；
   ±10% 已达 −20.080% / +21.690%。即需求侧 ±20% 的预测误差会突破 25% 费用包络。
2. **price**：±5/10/20% 的传导近似线性（−5.000%/+5.000% … −20.000%/+20.000%），
   单参数不放大；与 load 叠加时最不利（F1 = +73.986%）。
3. **pv**：−20% → +20.332%；+20% → −12.107% 且产生 3258.395 kWh 弃光。
4. **单向效率 η（0.9 → 0.81 / 0.99）**：+7.861% / −6.922%（往返 0.9 口径 −3.773%），
   二阶敏感但在包络内。
5. **组合压力（F 组，未纳入 C3 包络组，仅作信息登记）**：
   F1 +73.986%、F3 +68.539%、F4 −40.873%、F5 −29.047%、F2 +15.990%。
6. **结构/口径假设稳健**：asm-02 端点（B1 +0.018%、B2 −0.013%）、
   asm-03 零收益反送（与基线差值 0）、asm-05 并网点计量（−0.072%）、
   asm-12 整体错位（−0.000285%）的幅度均 ≤ 0.073%，不改变任何核心结论。

## 5. 结构结论与弃光

- 弃光 > 0 的 5 个情景：`A2_no_storage` 6247.963 kWh（无储能参照，必然弃光）、
  `E_load_-20pct` 2166.796 kWh、`E_pv_+20pct` 3258.395 kWh、
  `F4_pv+20_load-20` 11166.599 kWh、`F5_price+20_pv+20_load-20` 11166.599 kWh。
  即：**只有在需求显著下降或光伏显著增加导致正余电超过储能吸收能力时才被迫弃光**；
  基线与其余 38 个情景弃光为 0。
- 基线最优解贴运行边界（`E_max = 10800` 上界与 `E_min = 1200` 下界均被贴到）：
  **「贴界」是运行约束下的最优性质，不等于设备余量**，不得据此推断储能裕度。
  B 组端点情景显示：终端电量 ±1200 kWh 仅改变费用 ±0.018%，
  但 `E_max` 收紧到 9600 kWh 会使费用上升 +2.575%，说明运行上界是**有效约束**。

## 8. post-hoc 口径解释（不修改任何预注册阈值或 verdict）

> 以下为运行后追加的定量解释，**仅供 Level 6 与论文边界参考**，不改变 plan.md 的判据、阈值与 `fragile` 判定。

1. **C4(a) 未通过完全由无储能参照驱动**：唯一必然弃光且被设计为「无储能」的情景是
   `A2_no_storage`（6247.963 kWh）。若把该参照从分子/分母同时剔除，
   无弃光占比为 **38/42 = 90.476% ≥ 90%**，C4(a) 将通过；按预注册含参照口径则为
   38/43 = 88.372%。两种口径的差异只源于是否把「刻意构造的无储能情景」计入分母。
2. **C4(b) 的参照口径不匹配**：原实现用基线 `A2` 的 48052.047 元作为所有情景的统一参照，
   而 E_load_+20%、F1、F3 的负荷被放大到 ×1.2，「同条件」无储能参照应更高
   （E_load_+20% 为 62512.606 元、F1 为 75015.127 元、F3 为 70539.185 元）。
   按每情景自身 price/load/pv 缩放重算无储能参照后，**除无储能参照 A2（节省恒为 0）外的
   42 个情景全部严格低于同条件无储能费用**（如 E_load_+20% 节省 11582.721 元、F1 节省 13899.265 元、
   F3 节省 11336.614 元），即 **K3 在所有扰动条件下仍然成立**；
   重算公式在基线情景上精确复现 48052.046590846665 元，与 task 的 A2 结果逐位一致。
3. **C3 包络组未覆盖 η**：plan.md §2 的 C3 文本含「price / load / pv / Pmax / η」，
   而实现把包络组限定为 `D_power_cap / E_data_perturbation / G_time_label`，
   `C_efficiency`（η 的 ±5%/±10% 与往返口径）未进入 C3 判定集合。
   实测 η 场景最大偏差 7.861% ≤ 25%，**即使纳入也不改变 C3 的通过与 verdict**；
   但这是「预注册文本 vs 实现集合」的口径不一致，须作为技术债移交下一版本修正。
4. **预注册预测缺陷**：§6 的 B3 `not_up` 期望与可行域单调性矛盾；
   建议后续版本按「收紧上界 ⇒ 费用不降」登记方向。
