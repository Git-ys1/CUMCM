> 对象：`formulation.md` 的主模型 M1（式 (B)(S)(O)(C1)~(C8)）。
> 方法：只读数据探针 + 手工推导 + 小规模数值检查。**未对附件 1 的竞赛实例运行任何优化求解**，也未运行完整 MILP/worker，符合 `AGENTS.md` 的阶段边界；完整计算由 computation 阶段的隔离 task 承担。
> 工具：项目虚拟环境 `.venv`（Python 3.12.14、numpy 2.5.3、pandas 3.0.5、scipy 1.18.1 / HiGHS、openpyxl 3.1.5）。

## 1. 单位账本与量纲

| 式 | 量纲检查 | 结论 |
|---|---|---|
| (B) $q_t+pv_t dt+D_t-C_t-curtail_t=load_t dt$ | $[\text{kWh}]+[\text{kW}][\text{h}]+[\text{kWh}]-[\text{kWh}]-[\text{kWh}]=[\text{kW}][\text{h}]$ | 通过 |
| (S) $E_t-E_{t-1}=\eta_{ch}C_t-D_t/\eta_{dis}$ | $[\text{kWh}]=[-][\text{kWh}]-[\text{kWh}]/[-]$ | 通过 |
| (O) $\sum price_t q_t$ | $[\text{元/kWh}][\text{kWh}]=[\text{元}]$ | 通过 |
| (C6) $C_t\le Pbar\,y_t$ | $[\text{kWh}]\le[\text{kWh}][-]$ | 通过 |
| $Pbar=Pmax\,dt$ | $[\text{kW}][\text{h}]=[\text{kWh}]$ | 通过（$5000/6=833.3\overline{3}$ kWh） |

$-D_t/\eta_{dis}$ 一项把"并网点侧放电量"换算为"电池侧消耗量"，$\eta_{ch}C_t$ 把"并网点侧充电量"换算为"电池侧入账量"，两者单位均为 kWh，无量纲因子混入加减；单位账本中功率（kW）与电量（kWh）只通过 $dt$ 换算一次（`asm-09`），不存在二次混用。

## 3. 守恒关系

1. **逐时段能量守恒**：(B) 是并网点侧的严格等式；$curtail_t\ge0$ 保证"供电 $\ge$ 负载"。
2. **全天能量守恒（推导）**：对 (B) 求和并用 (C2)(C4)：
   $$\sum_t E_t-\sum_t E_{t-1}=E_{144}-E_0=0=\eta_{ch}\sum_t C_t-\frac{1}{\eta_{dis}}\sum_t D_t\ \Longrightarrow\ \sum_t D_t=\eta_{ch}\eta_{dis}\sum_t C_t=0.81\sum_t C_t .$$
   代回求和式得
   $$\sum_t q_t=\underbrace{\sum_t(load_t-pv_t)dt}_{=55541.9724\ \text{kWh}}+0.19\sum_t C_t+\sum_t curtail_t\ \ge\ 55541.9724 .$$
   该式同时说明：储能是净耗能环节（系数 $0.19>0$），储能循环越多，全天购电量越大；套利只能靠"低价时多购、高价时少购"的时移，而不是靠储能创造能量。与 §3.2 的经济机理一致。
3. **端点守恒**：$E_0=E_{144}=6000$ 使全天 SOC 净变化为零，(C2) 的递推链首尾闭合。

## 4. 边界与极限情形

| 情形 | 预期退化 | 检查 |
|---|---|---|
| $pv_t\equiv0$，$load_t,\ price_t$ 恒定，$Pbar>0$ | 无峰谷价差则套利无收益，储能不应动作；最优 $q_t=load\,dt$、$C_t=D_t=0$、$E_t\equiv E_0$ | 手算可行且满足 (C6)：任何 $C_t=D_t>0$ 都会因 $\eta_{ch}\eta_{dis}<1$ 使全天购电量增加 $\ge0.19m$，故 $m=0$。符号与方向正确。 |
| $Pbar\to0$（无充放电能力） | M1 退化为"只购电 + 弃光"模型；最优 $q_t=\max(load_t-pv_t,0)dt$、$curtail_t=\max(pv_t-load_t,0)dt$ | 与 §6 的可行性证书一致；$Cost_{day}=48052.0466$ 元。 |
| $\eta_{ch}=\eta_{dis}=1$ | (C2) 变为无损耗库存递推；全天守恒退化为 $\sum q_t=55541.9724+\sum curtail_t$ | 模型仍线性、仍有界；$0.19\sum C_t$ 项消失，套利收益只由价差决定。 |
| $load_t\equiv0,\ pv_t\equiv0$ | 最优 $q_t=0$，$Cost_{day}=0$ | $\min\sum price_t q_t=0$（$q\ge0$），下界可达，无无界性。 |
| $curtail_t$ 被强制取 0 且不可行 | 模型不可行 | 现行 (C8) 允许弃光，可行性由 §6 证书保证；若 computation 强制 $curtail\equiv0$ 后不可行，须按 `model_infeasible` 记录并回到 formulation，不得静默放松硬约束。 |
| $price_t$ 全相等（大于 0） | 无套利激励，$C_t=D_t=0$（同第 1 行） | 与 (O) 的单调性一致。 |
| $Emin=Emax$ | 储能无法动作，退化为 $Pbar=0$ 情形 | 当前数据 $Emin=1200<Emax=10800$，非退化。 |

## 5. 单调性与方向性

- **放宽 $Emax$（或 $Ecap$）**：可行域扩大，$Cost_{day}^\*$ 不增（`asm-08` 明确不得用 12000 作为运行上界，否则会低估费用）。
- **提高 $\eta_{ch},\eta_{dis}$**：给定 $C_t$ 时 SOC 入账更多、给定 $D_t$ 时 SOC 消耗更少，(C2) 约束放松，$Cost_{day}^\*$ 不增。故 `asm-04` 若把 90% 误取为往返效率（单侧 0.9487），$Cost_{day}$ 应下降或持平。
- **增大 $Pbar$**：(C5) 放松，$Cost_{day}^\*$ 不增。
- **电价整体上移 $\Delta p$**：$Cost_{day}^\*$ 关于 $price$ 线性非减，且最优解不变（目标系数同加常数不改变 argmin）。
- **放宽 $E_0=6000$ 为区间**：$E_{144}=E_0$ 的取值集合变大，$Cost_{day}^\*$ 不增。
- 上述方向性是可证的一般性质，可在 computation/robustness 中作为回代检查（违反即路由 formulation）。

## 6. 可行性证书与解析界（附件 1 只读探针）

只读汇总附件 1（144 行 × 3 列，标签 `00:10 … 0:00+1`，右端点口径）：

- $price_t\in[0.3713,1.3952]$ 元/kWh，$\bar p=0.7662$；$load_t\in[3309.39,5958.97]$ kW；$pv_t\in[0,7612.32]$ kW；
- $\sum load_t dt=111024.81$ kWh，$\sum pv_t dt=55482.84$ kWh，净缺额 $55541.97$ kWh；
- 正余电合计 $6247.96$ kWh，单时段最大余电 $352.92$ kWh，集中在 $t=58..87$（09:40–14:30）；单时段最大缺额 $826.08$ kWh。

**可行性证书**：$C_t=D_t=0,\ y_t=0,\ E_t\equiv6000,\ q_t=\max(load_t-pv_t,0)dt,\ curtail_t=\max(pv_t-load_t,0)dt$ 逐时段满足 (C1)~(C8)（平衡残差 $\le9.1\times10^{-13}$ kW 量级，纯浮点）。故 M1 可行，且

- 上界：$Cost_{day}^\*\le48052.0466$ 元（$Q_{day}=61789.9354$ kWh，弃光 $6247.963$ kWh）；
- 下界：由 §3.2 的 $\sum q_t\ge55541.9724$ kWh 与 $price_t\ge0.3713$ 得 $Cost_{day}^\*\ge20622.7344$ 元；
- 因单时段最大缺额 $826.08<$ $Pbar=833.33$ kWh，"逐时段购电下界" $\sum price_t\max((load_t-pv_t)dt-Pbar,0)=0$，该更紧的构造性下界在本数据上退化，故采用能量型下界。

## 7. 数值可解性与规模

- 规模：连续变量 720、0-1 变量 144、等式 288、不等式约 720；目标系数 $O(1)$，约束系数取值 $\{1,\ 0.9,\ 1/0.9\approx1.111\}$，右端项 $O(10^2\sim10^3)$ kWh。系数动态范围约 $10^3$，远低于双精度风险区间。
- 大 $M$ 紧性：$M=Pbar$ 由 (C5) 直接导出（§3.4），无"任意大数"；$M$ 过小会割掉可行解（例如 $M<352.92$ 将无法在最大余电时段满充），$M=Pbar$ 是唯一紧值。
- 退化性：LP 松弛存在多重最优（§8），求解器可能返回非互斥点；MILP 通过 (C6) 消除该歧义。建议 HiGHS 使用默认容差，并在报告中同时给出 `best_bound` 与 `mip_gap`。
- 有界性：$q_t\ge0$ 使目标有下界 0，§6 证书保证可行，故最优值存在（无需额外人工上界）。

## 8. I1 的数值检查（小规模、非竞赛实例）

目的：判断"LP 松弛是否已隐含互斥"（`assumption_v001` open_item I1）。做法为随机小规模实例上比较 LP 松弛与含 (C6) 的 MILP（`scipy.optimize.milp`/HiGHS），**不使用附件 1 的 144 时段实例**，以避免在看到计算结果前泄漏本问最优解。

- 第 1 组：4 000 个实例，$T=3..5$，$price_t\in[0.3,1.4]$，$load_t,pv_t\in[0,5]$，$Pbar\in[1,5]$，$Emax\in[3,12]$，$Emin=0$，$E_0$ 随机，$\eta=0.9$，$curtail_t$ 无上界。
- 第 2 组：6 000 个实例（2 470 个可解），$T=2..8$，$\eta\in\{0.9,0.9487,0.95\}$，$price_t\in[0,1.6]$，含 $curtail_t\le pv_t dt$ 上界。

结果：

| 项 | 第 1 组 | 第 2 组 |
|---|---|---|
| LP 目标值 $<$ MILP 目标值（差 $>10^{-7}$） | 0 例 | 0 例 |
| LP 目标值 $=$ MILP 目标值 | 全部 | 全部 |
| LP 原始解出现 $\min(C_t,D_t)>10^{-6}$ | 12 例（与 MILP 同值，属退化多重最优） | 2 例 |

**判定**：未发现"LP 松弛严格优于 MILP"的反例；但 LP 的**原始解**在退化实例中确实会同时充放电。因此：

1. 主模型保留 0-1 与 (C6)（`asm-06`），交付的 $C_t,D_t$ 必须来自 MILP 解或经互斥后处理；
2. LP 松弛仅用作下界与退化诊断，不得作为交付解；
3. 该结论限于本问可行域，不能外推为一般定理，也不得替代 computation 在真实实例上报告 $\max_t\min(C_t,D_t)$ 与 LP/MILP 目标差。
