## 3. 守恒关系

1. **逐时段计划层平衡**：(C1) 是并网点侧的严格等式；$\kappa\ge0$ 使 (B\*) 的「供电 ≥ 负载」自动成立。
2. **日循环下的充放电平衡**：对 (C2) 求和并用 (C4)：
   $$\sum_t E_{d,t}-\sum_t E_{d,t-1}=E_{d,144}-E_{d,0}=0=\eta_{ch}\sum_t C_{d,t}-\frac{1}{\eta_{dis}}\sum_t D_{d,t}\ \Longrightarrow\ \sum_t D_{d,t}=\eta_{ch}\eta_{dis}\sum_t C_{d,t}=0.81\sum_t C_{d,t}.$$
3. **日聚合计划恒等式**：把 (C1) 对 $t$ 求和并代入上式，
   $$\sum_t q_{d,t}=\sum_t\big(load_{d,t}-pv^{fc}_{d,t}\big)dt+\underbrace{(1-\eta_{ch}\eta_{dis})}_{0.19}\sum_t C_{d,t}+\sum_t\kappa_{d,t}.$$
   该式说明：计划购电量 = 预报净需求 + 储能循环损耗 + 计划弃光；储能是**净耗能**环节（系数 0.19），套利只能靠时移，不能创造能量。
4. **执行层恒等式**：把 (B-ex) 对 $t$ 求和并代入 §3.2 的充放电平衡与 (B)，
   $$\sum_t u_{d,t}-\sum_t\kappa^{act}_{d,t}=\sum_t\big(pv_{d,t}-pv^{fc}_{d,t}\big)dt-\sum_t\kappa^*_{d,t},
   \qquad
   \sum_t q^*_{d,t}+\sum_t u_{d,t}=\sum_t\big(load_{d,t}-pv_{d,t}\big)dt+0.19\sum_t C^*_{d,t}+\sum_t\kappa^{act}_{d,t}.$$
   故 $\sum_t(q+u)\ge\sum_t(load-pv)dt$，与 §6 的能量型解析界一致。
5. **数值核验（2 000 组随机小规模可行组合，`prob02_formulation_probe.json`）**：恒等式 (3) 的最大绝对误差 $9.09\times10^{-13}$ kWh、日循环平衡的最大绝对误差 $9.09\times10^{-13}$ kWh（纯浮点量级）。
6. **端点守恒**：$E_{d,0}=E_{d,144}=6000$ 使每日 SOC 净变化为零，(C2) 的递推链首尾闭合；执行层 $C,D$ 与计划层相同，故执行层端点亦为 6000。

## 4. 边界与极限情形

| 情形 | 预期退化 | 检查 |
|---|---|---|
| $pv_{d,t}\equiv pv^{fc}_{d,t}$（完全准确预报） | $s=\kappa^*\ge0\Rightarrow u\equiv0$，$\kappa^{act}=\kappa^*$ | (R) 直接给出；此时 M1 的 $Cost^{em}=0$，与 `alt-01` 的费用口径重合（但 `alt-01` 的计划依据是实际值，二者仅在本情形等价）。 |
| $\kappa^*_{d,t}\ge\big(pv^{fc}_{d,t}-pv_{d,t}\big)^{+}dt$ | 计划弃光松弛足以吸收全部预报缺口，$u_{d,t}=0$，$\kappa^{act}_{d,t}=\kappa^*-(pv^{fc}-pv)dt>0$ | 数值核验：`limit_cases.pf_gt_pa_kappa_covers`（缺口 166.67 kWh、$\kappa^*=200$ → $u=0$、$\kappa^{act}=33.33$）。说明**计划弃光率与紧急购电量不是彼此独立的**。 |
| $Pbar\to0$（无充放电能力） | M1 退化为「只购电 + 弃光」：$q=(load-pv^{fc})^{+}dt$、$\kappa=(pv^{fc}-load)^{+}dt$，而 $u=\big((pv^{fc}-pv)^{+}dt-(pv^{fc}-load)^{+}dt\big)^{+}$ | 与 §6 的可行性证书一致；因 $\sum_t(x_t)^+\ge(\sum_t x_t)^+$，逐时段判定的紧急购电量不小于「先按日聚合再取正部」的估计。 |
| $\eta_{ch}=\eta_{dis}=1$ | 0.19 项消失，$\sum_t q_t=\sum_t(load-pv^{fc})dt+\sum_t\kappa_t$，无循环损耗 | 模型仍线性有界；套利收益只由价差决定。 |
| $Emin=Emax=E_0$ | 储能不可动作，退化同上 | 当前数据 $1200<10800$，非退化。 |
| 强制 $\kappa_{d,t}\equiv0$ | **在存在不可避免弃光的时段不可行** | 证明：由 (C1) 得 $q_{d,t}=(load_{d,t}-pv^{fc}_{d,t})dt+C_{d,t}-D_{d,t}$。若 $(pv^{fc}-load)dt>Pbar$，则要与 $q\ge0$、$C\le Pbar$、$D\ge0$ 同时成立需 $C\ge(pv^{fc}-load)dt+D>Pbar$，矛盾。交付窗口内有 **272 个**预报时段满足 $(pv^{fc}-load)dt>Pbar$（实际口径 241 个），故 (C8) 的弃光松弛是**必需约束**，不得为「零弃光」而删除；若 computation 强制 $\kappa\equiv0$ 后报不可行，应记录为建模事实而非 `model_infeasible` 故障。 |
| 恒价且**无**弃光 | 无套利与无余电吸收激励 ⇒ $C=D=0$ | 由 §3.3 的 0.19 项与 $\kappa=0$ 直接得到。 |
| 恒价且**存在**不可避免弃光 | $C>0$ 仍可能最优：吸收本会被弃掉的余电，使 $\sum q$ 下降 $0.81$ 倍所吸收电量 | 由 §3.3 恒等式：吸收 $\delta$ 的余电使 $\kappa$ 减 $\delta$、使 0.19$\delta$ 进入损耗，净 $\Delta\sum q=-0.81\delta<0$。**故不得以「储能净耗能」为由断言恒价下 $C=D=0$**；computation 应报告此类「吸收益电」的时段。 |
| 去掉 (C4)（自由终端，`alt-07`） | 可行域扩大，$Cost^{plan}$ 不增，但出现「首日放空至 $Emin$」的透支伪解 | 日循环 (C4) 是本题（问题 1「0:00 与 24:00 储电量相同」的逐日版本）的题面/假设要求，必须保留。 |
| $E_0$ 由 6000 变为其他值 | $Cost^{plan}$ 单调不增（可行域随 $E^{cyc}$ 的集合扩大而扩大） | robustness 对 $E^{cyc}\in\{4800,6000,7200\}$ 做对照；本版本固定 6000（`asm-06`/`asm-16`）。 |

## 5. 单调性与方向性

- **$\eta_{ch},\eta_{dis}$ 提高**：给定 $C$ 时 SOC 入账更多、给定 $D$ 时 SOC 消耗更少，(C2) 放松且 0.19 系数变小，$Cost^{plan\*}$ 不增。故若 90% 实为往返效率（单侧 0.9487），本模型给出的费用应偏高。
- **$Pbar$ 增大**：(C5) 放松，$Cost^{plan\*}$ 不增；同时 $\kappa$ 有更大空间被吸收，$Cost^{em}$ 亦不增。
- **$Emax$ 放宽**（如误用 $Ecap=12000$）：可行域扩大，$Cost^{plan\*}$ 不增——`asm-11` 明确禁止，否则低估费用与弃光。
- **$price_t$ 整体平移 $\Delta p$**：$Cost^{plan\*}(\Delta p)=Cost^{plan\*}(0)+\Delta p\sum_t q^\*_t$，最优解不变（目标系数同加常数不改变 argmin）。
- **$pv^{fc}_{d,t}$ 提高**（预报更乐观）：计划层可用能量增加，$Cost^{plan\*}$ 不增；同时 $s=\kappa^*+(pv-pv^{fc})dt$ 减小，$Cost^{em}$ 不减（方向相反）——这是本模型的核心张力，也是 `alt-02`（典型日预测）会放大紧急购电的原因。
- **$pv_{d,t}$ 提高**（实际更充足）：对固定 $\kappa^*$，$s$ 增大 ⇒ $u$ 非增、$\kappa^{act}$ 非减 ⇒ $Cost^{em}$ 不增。
- **$\kappa^*_{d,t}$ 增大**：$u$ 非增（计划弃光可吸收缺口）、$\kappa^{act}$ 非减；因 $\kappa$ 不进入计划层目标，计划层对 $\kappa$ 的取值只在「被迫为正」时确定（§4.3 of `formulation.md`）。
- 上述方向性均为可证的一般性质，可在 computation / robustness 中作为回代检查（违反即路由回 `mathematical_formulation`）。

## 7. 数值可解性与规模

- **逐日规模**：连续变量 720（$q,C,D,E,\kappa$）、0-1 变量 144；等式 289（平衡 144 + SOC 递推 144 + 终端 1）；不等式 1 008（(C3) 288 + (C5) 288 + (C6) 288 + (C8) 144）。全年总计 334 个互相独立的问题、48 096 个 0-1。
- **系数与尺度**：约束系数取值 $\{1,\ 0.9,\ 1/0.9\approx1.1111\}$，右端项 $O(10^0\sim10^4)$ kWh，目标系数 $O(10^{-1}\sim10^{0})$ 元/kWh；动态范围约 $10^4$，远低于双精度风险区间。
- **大 $M$ 紧性**：$M=Pbar$ 由 (C5) 直接导出，无「任意大数」；$M<Pbar$ 会割掉可行解（如 1 100.332 kWh 的余电时段需要满充吸收）。
- **有界性**：$q\ge0$、$price_t>0$ 使 (O) 有下界 0；§6 证书保证可行 ⇒ 最优值存在，无需人工上界。
- **求解器容差（本阶段发现，转 implementation）**：HiGHS 默认 `mip_rel_gap=1e-4`，会把 gap 内的可行解报为 `status=0`。同一随机小规模实例在默认容差下曾出现「LP 比 MILP 低 0.319 元」的假象，把 `mip_rel_gap` 显式设为 $10^{-9}$ 后该差值为 $4.5\times10^{-13}$ 元。故任务规格必须显式设定 `mip_rel_gap`（建议 0 或 $\le10^{-6}$），并在报告中同时给出 `best_bound` 与 `mip_gap`；不得仅凭默认容差下的 `status=0` 宣称逐日全局最优。
- **退化性**：计划层可能在多个最优解之间退化（费用相同、$C/D$ 不同），交付的 $C,D$ 必须取自 MILP 解或经互斥后处理；不同最优解会给出不同的 $\kappa^*/u/\kappa^{act}$ 明细。

## 8. 互斥性与 LP 松弛的随机小规模检查（非竞赛实例）

目的：回答「本问计划层是否可以省略 0-1 与 (C6)」。做法为随机小规模实例（$T=3..6$，$price\in[0.3,1.4]$，$load,pv\in[0,6000]$，$Pbar\in[50,833.33]$，$\eta\in\{0.9,0.9487,1.0\}$，含 (C8) 弃光上界）上比较 LP 松弛与 MILP（`scipy.optimize.milp`/HiGHS，`mip_rel_gap=1e-9`），**不使用交付窗口的 144 时段实例**，避免在看到计算结果前泄漏本问最优解。

| 项 | 结果（400 个实例） |
|---|---|
| 不可行实例 | 0 |
| LP 原始解出现 $\min(C,D)>10^{-6}$ | 0 |
| MILP 原始解出现 $\min(C,D)>10^{-6}$ | 0 |
| LP 目标严格优于 MILP（差 $>10^{-7}$） | 0（最大 $|{\rm MILP}-{\rm LP}|=4.5\times10^{-13}$） |

**判定**：（a）本组实例中 LP 松弛的**原始解**未出现同时充放电，与 prob01 的 6 470 实例结果（少数退化实例出现）不矛盾，但**未能复现**该退化；（b）未发现 LP 严格优于 MILP。这两条都只是数值证据、不是定理，也未经竞赛实例验证。因此本版本的结论是：**保留 0-1 与 (C6)**（`asm-10` 的物理要求）；LP 松弛仅作下界与退化诊断，不得作为交付解，也不得据此声称「松弛路线可行」。该结论不外推到 prob03/prob04。

## 9. 执行层投影 (R) 的独立数值核验

在 20 000 组随机可行组合 $(\text{load},pv^{fc},pv,C,D,\kappa^*)$（$\kappa^*=\max(0,(pv^{fc}-load)dt+D-C)$、$q=\max(0,(load-pv^{fc})dt+C-D)$）上核验 (R)：

| 检查项 | 结果 |
|---|---|
| (B-ex) 执行层平衡残差 $\max|q^*+u+pv\,dt+D^*-C^*-\kappa^{act}-load\,dt|$ | $6.8\times10^{-13}$ kWh |
| 互补性违反 $\max u\kappa^{act}$ | 0 |
| $u<0$ 或 $\kappa^{act}<0$ 的组合数 | 0 |
| 违反 $u\le(pv^{fc}-pv)^{+}dt$ 的组合数 | 0 |
| 若误按「计划层 $\kappa^*$ 计入缺口」的字面式：$u>0$ 且 $\kappa^{act}>0$ 并存的组合数 | 5 092 |
| 计划弃光松弛吸收全部缺口（$u=0$ 且 $\kappa^*>0$）的组数 | 2 397 |

结论：投影式 (R) 是唯一同时满足执行层平衡与互补性的闭式；字面读法（把计划层 $\kappa^*$ 代入缺口式）会产生「同时紧急购电与弃光」的矛盾，**implementation 必须按 (R) 实现**（`formulation.md` §3.7 的 warning）。另由 $\kappa^*\le pv^{fc}dt$ 可证 $\kappa^{act}\le pv_{d,t}dt$：$\kappa^{act}=\max(0,\kappa^*+(pv-pv^{fc})dt)\le\max(0,pv^{fc}dt+(pv-pv^{fc})dt)=pv\,dt$。

## 10. 交付口径的独立核验（歧义 A9 / A-D1）

只读读取附件 5 `result2.xlsx`：
