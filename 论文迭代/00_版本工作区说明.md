# 论文迭代 · 版本工作区

> 建立：2026-09-12 ｜ 维护：WorkBuddy
> 用途：**存放各版本论文正文 TeX**，供"人工编辑 → WorkBuddy 审查 → MathModel 修改并编译"的循环使用。

---

## 一、目录约定

```
论文迭代/
├─ 00_版本工作区说明.md      ← 本文件
├─ _模板/                    ← 新建版本时从这里复制文件名（内容为空占位）
├─ V4.1/                     ← 你自建：版本号目录
├─ V5/                       ← 你自建
└─ V5.1/ …                   ← 依此类推
```

**新增一版时**：在 `论文迭代/` 下新建以版本号命名的文件夹，把改好的 tex 文件放进去即可。
WorkBuddy 会审查该文件夹，**不会**改动你的原始文件（审查意见另出文档）。

---

## 二、每个版本文件夹应包含的同规格文件

与 `MathModel\paper\texfile\` 完全对应的 10 个 tex（**文件名必须一致**，否则编译无法 `\input`）：

| 文件名 | 内容 |
|---|---|
| `1abstract.tex` | 摘要 + 关键词 |
| `2ProblemRestatement.tex` | 一、问题重述（含问题背景/问题提出/研究现状综述） |
| `3ProblemAnalysis.tex` | 二、问题分析 |
| `4AssumptionAndSign.tex` | 三、模型假设 + 四、符号说明 |
| `5MakeModel.tex` | 五、数据预处理 + 六、模型的建立与求解（四问） |
| `6ErrorAnalysis.tex` | 七、模型检验与分析（含灵敏度） |
| `7ModelEvaluation.tex` | 八、模型的评价 + 九、改进与推广 |
| `8AIUsageStatement.tex` | AI 工具使用声明 |
| `8Reference.tex` | 参考文献 |
| `9Appendix.tex` | 附录（支撑材料清单 + 源码） |

> 图件目录 `figures/` 由 MathModel 工程提供，**版本文件夹只需放 tex**；如需指定新图，请在文件夹内附说明。

## 三、循环流程（V5 起生效）

1. **MathModel** 完成建模与算法修正、重跑结果、更新 `numbers.tex` 与 `generated/`（数字只由代码来）。
2. **团队/用户** 在本工作区新建版本文件夹，人工编辑 tex（或交由 GPT 网页端写作后放回）。
3. **WorkBuddy** 审查该版本，出具《建议稿》，核对：
   - 是否满足 **V5 审阅条件**（见下方清单）
   - 是否符合 **全糖奶茶屋两篇示例**的写法范式（公式典范 / 段落与图表衔接）
   - 数值与代码是否一致（禁止手写数字）
4. **MathModel** 按建议稿**小幅修改**并**编译为 PDF**。

## 四、V5 审阅条件（每版必查）

### 硬性（违反即打回）
- [ ] 正文 **≤30 页**；摘要 ≤1 页；**无目录**；匿名（无校名/姓名/队号）
- [ ] 四个指定日期 **2025-03-20 / 06-21 / 09-23 / 12-21** 的表 1–3 结果在正文
- [ ] Q3 采用**差额部分结算**：`p·min(Gᵖ,Gᵃ) + 0.5p(Gᵖ−Gᵃ)⁺ + 1.5p(Gᵃ−Gᵖ)⁺`，不足加 `5pE`
- [ ] 所有结果数字来自宏（`\Qxxx`），**无手写数字**
- [ ] AI 声明位于参考文献之前；《AI工具使用详情.pdf》独立
- [ ] 无内部版本号 **V3/V4/V5** 等字样（版本号只用于本工作区目录名）

### 叙事与语言（V5 指导书）
- [ ] 假想读者是"第一次看到这篇论文的人"；无"我们此前/旧结果/两种口径之争"等对话痕迹
- [ ] 顺序为**朴素解释 → 数学表达 → 专业名称**
- [ ] "口径"一词大幅降频（结算口径→结算规则/计费方式；效率口径→效率定义；主口径→主模型）
- [ ] 无 `mutation` / `legacy` / `消融`（改"对照实验"）等工程术语
- [ ] "有正收益"不写成"必要"；局部边际结论（4:1）不写成全局结论

### 全糖奶茶屋示例对齐
- [ ] **公式典范**：目标函数与约束完整、集中陈述（"综上所述，模型为"式）
- [ ] **段落与图表衔接**：每段图/表前有引出、后有结论解释；图说趋势、表给数值但**不重复同一组数据**
- [ ] 波动电价部分不重复介绍已定义的符号，只说清"替换了价格矩阵"

---

## 五、纪律

- **禁止手写/手改任何结果数字**——一律由 `numbers.tex` 宏注入。
- **禁止改 C 级生成物**（`numbers.tex`、`generated/*.tex`、`result*.xlsx`）。
- **禁止改 D 级内核**：公共物理模型、因果信息集、MILP 充放互斥、计划持续性。
- **禁止复制参考范文**（含全糖奶茶屋示例）的文字、公式、图表——只学写法与格式。
- 每版修改后需重新编译核页并重跑测试。
