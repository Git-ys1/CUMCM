# C题论文 V5 文字重写稿说明

## 1. 本轮任务边界

本稿只重写论文叙事、段落组织与公式/图表衔接，不主动更换已经锁定的模型、参数、数值宏、图表数据和结果工作簿。数值仍通过现有 `paper/numbers.tex` 与 `generated/*.tex` 引用，因此正式合并时不要手工复制或修改结果数字。

本轮以“第一次看到论文的评委”为唯一假想读者：任何概念都先说明为什么出现，再给数学表达；任何公式都解释各项代表什么以及为什么这样写；任何图表都在出现前说明它要回答的问题，在出现后提炼可观察事实、解释机制并自然引向下一段。

## 2. 参考写法

重点吸收两份“全糖奶茶屋”参考稿的段落组织方式：

- 先从物理/经济现象出发，再引出目标函数或约束，而不是直接堆公式；
- 每个目标函数都采用“决策背景 → 公式 → 各项含义 → 经济解释”的顺序；
- 每类约束采用“为何需要 → 数学式 → 对运行的限制”顺序；
- 图表采用“为什么画 → 图/表 → 读出什么 → 为什么会这样 → 对模型结论意味着什么”的闭环；
- 结果部分不只重复数字，而是解释费用变化、储能动作和信息更新之间的因果链。
