## 二、🔴 P0 阻塞项（必须改）

### P0-1｜Q3 主结算口径方向反了（最高优先）

**问题**：V5 仍以 **additive（全额计划费 + 额外调整费）为主**、**差额结算为对照**；而团队 2026-09-12 已拍板**完全相反**。

依据（团队决定 + 全糖奶茶屋视频佐证）：题面"**部分**""超出部分""**违约电价**"，且讲者举例"少买仍然**省了钱**，只是要罚 0.5 倍"——只有差额部分结算使总费用低于不调整，additive 会使"少买反而多花钱"、抑制向下调整（外部评论已有人因此得出"不调整最省钱"的错误结论）。

**涉及位置（逐条）**：

| 文件:行 | 现状 | 应改为 |
|---|---|---|
| `1abstract.tex:11` | "本文主模型按…**叠加口径**结算，并同时保留**差额结算**作为敏感性对照" | 主模型采用**差额部分结算**；另一种解释降为对照/一句说明 |
| `5MakeModel.tex:349` | "本文主模型采用题面…并列相加的解释" | 改为"按题面对'部分/超出部分'的措辞，未调整部分按正常电价、差额部分按 0.5/1.5 倍" |
| `5MakeModel.tex:352` | `C_t^{\text{add}}=\pi_tG^p_t+0.5\pi_tv_t+1.5\pi_tu_t` 作为主式 | 主式改为 `C_t=\pi_t\big[\min(G^p_t,G^a_t)+0.5v_t+1.5u_t\big]`（即现 L359 的 rep 式），并**改掉 `add`/`rep` 这类英文缩写标签** |
| `5MakeModel.tex:356` | "本文同步建立差额结算对照" | 改为"作为对照，另一种理解为…（现 L352 的形式）" |
| `5MakeModel.tex:359` | 现 rep 式作为对照 | 升为主式（见上） |
| `5MakeModel.tex:412` | 表题"（**主结算口径**）" | 改为"（差额部分结算，主结果）"；并去掉"口径" |
| `5MakeModel.tex:479` | "另一种差额结算口径…为 `\QthreeRepTotal`" | 主结果改为 `\QthreeRepTotal`；另一种解释的结果降为对照句 |
| `6ErrorAnalysis.tex:41` | 手算校验段落以 add 为主 | 主/次对调；数值 900→700：主式 **800**，对照式 **1000** |

**数值连带影响（重要）**：
